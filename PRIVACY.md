# Privacy Notice

GitTerm Profile Studio retrieves publicly available information from the GitHub REST API after a visitor enters a GitHub username.

## Data processed

The application may display public profile and repository information returned by GitHub, including usernames, avatars, biographies, public repository metadata, follower counts, stars, forks, and programming-language labels.

## Data storage

The application runs in the visitor's browser. This version does not maintain a backend database and does not intentionally store GitHub profile data, passwords, access tokens, or private repository information.

## GitHub

Requests to the GitHub REST API are subject to GitHub's own terms and privacy practices.
