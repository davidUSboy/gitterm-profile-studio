# Support

For bug reports, feature requests, or questions about GitTerm Profile Studio, use one of the following channels:

- Open a GitHub issue in this repository.
- Email: `lavrusha200@gmail.com`

## What to include

Please provide:

- the GitHub username you attempted to inspect;
- the displayed error message;
- your browser and operating system;
- steps that reproduce the problem;
- a screenshot, when useful.

Do not send passwords, personal access tokens, OAuth secrets, or other credentials.
